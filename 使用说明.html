黑猫智记AI · 使用说明

适用版本 v0.2.17 · 自动填表 + 自动发布 + 自动连发

本地图片文件夹 AI 生成笔记 浏览器插件发布 CDP 真实发布

1安装与启动

  1. 运行安装包 黑猫智记AI-0.2.17-setup.exe，一路下一步完成安装。
  2. 默认安装目录：C:\Users\25147\AppData\Local\Programs\黑猫智记AI\若你自定义了路径，请记住它，第 4 步加载插件要用。
  3. 从开始菜单或桌面快捷方式打开「黑猫智记AI」，会自动弹出主窗口（含选品 / 笔记生成 / 批量发布 / 历史 / 设置 ��标签页）。
  4. 首次启动会在 AppData\Roaming\xhs-assistant-prototype\data 生成数据目录（图片、笔记、设置都存这）。
若打开后主窗口空白，先确认端口 5199 没被其它程序占用；关闭重开即可。

2准备内容（三种图片来源，任选其一）

方式 A：本地图片文件夹（按 id 读图发布，推荐）

① 在软件数据目录的 images/ 下，给每篇笔记建一个文件夹，文件夹名就是这篇笔记的 id： …\xhs-assistant-prototype\data\images\我的穿搭01\ ← 里面放这组笔记的图片 …\xhs-assistant-prototype\data\images\美食探店02\ ← 里面放图片 ② 每个文件夹里放图片（jpg / png / webp 均可）。可选放 name.txt 作为文案灵感（标题/正文参考）。
图片根目录可在「设置 → 发布方式 → 图片根目录」改成任意本地图库路径（如 D:\我的图库），软件只读取不移动。
③ 回到软件「选品」页，点 📁 扫描图片文件夹，会列出所有待发组（显示张数、缩略图、文案种子）。 ④ 勾选要发的组 → 点 导入选中 或 导入全部并生成笔记。标题/正文/话题由 AI 按文件夹名（或 name.txt）自动生成。

方式 B：选品（商品 URL 抓取）

① 在「设置 → 发布方式」填好「商品页 URL」。 ② 「选品」页点「抓取」，把商品图与信息拉进商品库。

方式 C：手动录入商品

在「选品」页手动新增商品，填写商品图 URL 等，进入商品库后走同样的笔记生成流程。

3生成笔记文案

  1. 切到「笔记生成」页，你会看到已导入的笔记草稿（标题 / 正文 / 话题 由 AI 生成）。
  2. 在「设置 → 发布设置」里可勾选要生成哪些项：生成标题生成正文生成话题。
  3. 需要的话手动微调文案，确认无误后进入发布。

4发布方式一：浏览器插件（你正在用的，推荐）

① 加载插件（只需做一次）

1. 打开浏览器（Chrome 或 Edge），地址栏输入：chrome://extensions 或 edge://extensions。 2. 右上角打开 开发者模式 开关。 3. 点 加载已解压的扩展程序，选择插件文件夹： C:\Users\25147\AppData\Local\Programs\黑猫智记AI\resources\app.asar.unpacked\extension 4. 加载成功后，扩展列表会出现「黑猫智记AI」。以后软件升级，回到这里点 重新加载 即可。

② 开始自动发布

1. 浏览器登录账号，打开 创作者中心 creator.xiaohongshu.com，进入「发布笔记」创作页。 2. 页面右侧会出现 🚀 发布助手 侧栏（也可点扩展图标）。 3. 点浏览器插件「开始批量发布」→ 插件自动逐篇从队列取笔记 → 填入标题/正文/话题 → 注入图片 → 自动点「发布」→ 自动连发下一篇。 4. 想中途停下：切到别的标签或关掉创作页即可。
自动提交已默认开启（v0.2.17 起）。若你想每篇自己核对再发：在插件 popup 把「自动提交」关掉——此时插件会填好停住等你点发布，你点完「发布」成功后会自动连发下一篇。

6常用开关与数据管理

  • 自动提交 / 自动发布：插件 popup 或「设置 → 发布设置 → 自动提交」切换。
  • 模拟真人打字：默认开，发布时逐字输入更像人工；可在设置关闭。
  • 清除发布数据：「设置 → 数据管理 → 清除发布数据」（红色按钮）会清空笔记/商品/历史/已导入记录，可重新导入图片文件夹重发。设置与账号信息不会被清。
  • 图片根目录：设置里可改成本地图库路径。

7常见问题排查

停在「请人工复核」没反应

确认插件 popup 里「自动提交」是开；或关掉它后手动点「发布」。升级到 v0.2.17 后默认即自动发布。

点了「开始批量发布」没反应

确认当前在 creator.xiaohongshu.com 创作页；确认插件已「重新加载」到最新版；确认队列里有笔记（笔记生成页有草稿）；确认后端已启动且「生成笔记」已入队。

弹出验证/滑块挑战

软件不会自动破解验证，会停下转人工。手动完成验证后继续即可。

图片不显示 / 上传失败

确认图片文件夹里是常见格式且未损坏；本地图片走内置文件服务，无需联网。

任何环节卡住，把「🚀 发布助手」侧栏里的提示文字发给我，我就能定位具体卡点在哪。
