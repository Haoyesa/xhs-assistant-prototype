扩展身份设置

比特浏览器多账号并行发布时，每个窗口的扩展需绑定一个后台账号。

本地服务端的地址，默认 http://127.0.0.1:5199。
选择后台「账号」页里的一个账号。服务端只把该账号的任务下发给本窗口，实现多账号并行互不抢。
本窗口对应的比特浏览器配置 ID（UUID）。后台账号页「打开窗口」按钮会拿这个 ID 调比特 Local API 打开本窗口。打开比特客户端 → 对应窗口 ⋮ →「复制窗口 ID」后粘贴。
使用流程：① 后台「账号」页添加并确认要用的小红书账号；② 每个比特窗口打开本设置页，绑定对应账号并保存； ③ 后台「发布」页把笔记任务「批量指派」给该账号；④ 各窗口的扩展各自拉取自己账号的任务并行发布。
